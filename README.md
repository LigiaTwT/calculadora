# Cute Calculator

> Uma calculadora web fofa e interativa, desenvolvida como projeto de aprendizado em frontend e 3D para web.

## ✨ Sobre o projeto

Este projeto nasceu a partir da evolução de uma calculadora antiga que desenvolvi anteriormente.

A proposta é transformar o projeto em uma experiência visual moderna, explorando desenvolvimento frontend, UI/UX, animações e posteriormente 3D para web.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Three.js — planejado para a etapa 3D

## 🎯 Objetivos

- Melhorar a arquitetura do projeto
- Criar uma identidade visual própria
- Desenvolver uma interface bonita e responsiva
- Aprender CSS 3D
- Aprender os fundamentos do Three.js
- Explorar modelos e elementos 3D na web

## 🚀 Como executar

Clone o repositório e abra o `index.html` no navegador.

## 📚 Aprendizados

Este projeto está sendo desenvolvido de forma incremental para aprender na prática conceitos de frontend, design e desenvolvimento 3D para web.
